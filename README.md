# AI Call Assistant

An intelligent, context-aware AI Call Assistant designed to help users manage incoming calls based on their current situation and preferences.

##  Overview

AI Call Assistant is an AI-powered application that can handle incoming calls on behalf of the user. It provides different modes to control how calls are managed, helping users stay focused while reducing unnecessary interruptions.

##  Features

-  **AI-Powered Call Handling** – Responds to incoming calls intelligently.
-  **Study Mode** – Helps minimize interruptions while the user is studying.
-  **Sleep Mode** – Manages calls during sleeping hours.
-  **Normal Mode** – Handles calls normally when the user is available.
-  **Context-Aware Responses** – Uses AI to provide appropriate responses based on the selected mode.
-  **Automated Call Management** – Reduces the need to manually handle every incoming call.

##  Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **AI:** LLM API Integration
- **Development Tools:** Git, GitHub, VS Code

##  How It Works

1. The user selects a preferred mode.
2. The application detects an incoming call.
3. The AI assistant handles the call according to the selected mode.
4. The assistant generates an appropriate response using AI.
5. Call-related information can be managed through the application.

##  Project Objective

The main objective of this project is to develop an intelligent call-management system that uses artificial intelligence to handle calls according to the user's context, helping improve productivity and reduce unnecessary interruptions.
